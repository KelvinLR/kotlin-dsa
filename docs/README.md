# 📖 Documentação e Anotações

Esta pasta contém anotações teóricas e explicações sobre os conceitos estudados.

- **complexidade.md** — Guia de notação Big-O e análise de complexidade

## Dicas de estudo

1. **Entenda antes de implementar** — Leia a teoria antes de codar
2. **Analise a complexidade** — Sempre pense em tempo e espaço
3. **Teste com casos extremos** — Lista vazia, um elemento, valores negativos
4. **Refatore** — Volte e melhore suas soluções anteriores
